BLADE STUDIO - 3D blade configurator demo
==========================================

Single file: index.html (Three.js r160 from CDN, no build step).

PUT IT ONLINE (2 minutes, free)
1. Go to https://app.netlify.com/drop
2. Drag this whole "demo" folder onto the page
3. You get a live link like https://something.netlify.app
   (Site settings > change site name, e.g. blade-configurator-demo)

Other option: GitHub Pages (new repo, upload index.html, Settings > Pages).
Note: opening index.html straight from disk also works in Chrome/Edge.

WHAT IS IN THE DEMO
- Real-time 3D blade, PBR materials, studio lighting, soft shadows
- Procedural wood (limba, koto, hinoki, walnut, ebony, ayous, kiri, ash, wenge)
- Real ply build-up: 5-ply wood or 5+2 carbon / arylate carbon / zylon carbon
- Ply detail view + exploded "Show ply layers" view
- Color stains, natural / satin / gloss finish (clearcoat)
- 4 handle shapes (FL, ST, AN, CO), handle wood, accent line color
- Personal engraving on the handle (laser / gold / silver)
- Rubber preview (red / black)
- Live price and estimated weight (from real wood densities and volume)
- Save HD render: PNG up to 3600 px with transparent background
- Add to cart summary (in the real shop this goes to the WooCommerce cart)
